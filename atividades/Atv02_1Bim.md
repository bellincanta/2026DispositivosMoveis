# Atividade Avaliativa – App Biscoito da Sorte

## 1. Proposta da atividade
Cada aluno deverá desenvolver individualmente um aplicativo em **React Native** chamado **Biscoito da Sorte**.

O aplicativo deverá apresentar, inicialmente, a imagem de um biscoito fechado. Ao clicar em um botão, o sistema deverá exibir uma **frase aleatória** e trocar a imagem para um **biscoito aberto**.

A atividade também inclui uma **apresentação oral**, na qual o aluno deverá explicar o processo de desenvolvimento do projeto **desde o início**.

---

## 2. Objetivos de aprendizagem
Nesta atividade, o aluno deverá demonstrar que é capaz de:

- criar um projeto em React Native;
- utilizar componentes visuais da interface;
- trabalhar com imagens no aplicativo;
- implementar eventos de clique;
- utilizar **state** para atualizar a interface;
- realizar sorteio de elementos de um vetor;
- organizar o código de forma clara;
- explicar oralmente como o aplicativo foi construído.

---

## 3. Contexto da atividade
O projeto-base analisado utiliza os seguintes elementos principais:

- componente de classe;
- `state` para controlar a frase e a imagem exibida;
- `Image` para mostrar o biscoito;
- `TouchableOpacity` para o botão;
- vetor de frases;
- geração de índice aleatório com `Math.random()`;
- atualização da interface após a ação do usuário.

Com base nessa proposta, o aluno deverá reproduzir e compreender a lógica do aplicativo.

---

## 4. Descrição do que deve ser desenvolvido
Cada aluno deverá implementar um aplicativo com as seguintes características:

- ao abrir o app, deve ser exibida a imagem de um **biscoito fechado**;
- deve existir um botão com a ação de quebrar o biscoito;
- ao clicar no botão, o aplicativo deve:
  - sortear uma frase aleatória;
  - exibir a frase na tela;
  - trocar a imagem do biscoito fechado para a imagem do biscoito aberto.

---

## 5. Requisitos obrigatórios
O trabalho deverá conter obrigatoriamente:

1. **Imagem do biscoito fechado** na tela inicial.
2. **Imagem do biscoito aberto** após a interação do usuário.
3. **Botão funcional** para executar a ação principal do app.
4. **Vetor/lista com pelo menos 7 frases** diferentes.
5. **Sorteio aleatório** de uma frase ao clicar no botão.
6. **Exibição da frase sorteada** na tela.
7. Uso de **state** para controlar as informações exibidas.
8. Organização visual mínima, com alinhamento dos componentes.

---

## 6. Requisitos desejáveis
Também serão valorizados os seguintes aspectos:

- botão para reiniciar o aplicativo;
- melhoria visual da interface;
- comentários explicativos em partes importantes do código;
- código bem organizado;
- nomeação clara de variáveis, métodos e estilos.

---

## 7. Entrega
A forma de entrega será:

**link do repositório GitHub contendo o projeto completo**

### Importante
- O repositório deve conter todos os arquivos necessários para execução do projeto.
- **A pasta `node_modules` não deve ser enviada para o GitHub.**
- O projeto deve estar organizado e funcional.
- Recomenda-se incluir um arquivo `README.md` simples com instruções de execução.

## 9. Critérios de avaliação
A nota poderá ser distribuída da seguinte forma:

### Parte prática – 7,0 pontos
- Funcionamento correto do aplicativo – **2,0**
- Uso adequado de componentes e eventos – **1,5**
- Uso correto de `state` – **1,5**
- Organização e clareza do código – **1,0**
- Interface e apresentação visual – **1,0**

### Apresentação oral – 3,0 pontos
- Explicação do processo de desenvolvimento – **1,0**
- Domínio do código implementado – **1,0**
- Clareza na apresentação – **1,0**

---

## 10. Orientações gerais

- O trabalho deve ser desenvolvido de forma individual.
- Será verificado plágio entre trabalhos de colegas, materiais da internet e outras fontes.
- Também será verificado o uso de Inteligência Artificial na produção do trabalho.
- Caso sejam identificados plágio ou uso indevido de IA, o trabalho poderá receber as penalidades definidas pelo professor.
- O aluno deverá estar preparado para explicar oralmente todas as partes do projeto, desde a criação inicial até a implementação final.
