# Dispositivos Móveis — 31593 (TECNOLOGIA.0184) | Graduação
## Desenvolvimento para Dispositivos Móveis — 67 h / 80 aulas

**Docente:** Prof. Dr. Nelson Bellincanta Filho  

---

## Visão geral
A disciplina aborda o desenvolvimento de **aplicações para dispositivos móveis** com foco em **React Native + Expo**, cobrindo fundamentos de **arquitetura mobile**, **componentes e navegação**, **consumo de APIs**, **persistência local**, e integração com **back-end**. Ao longo do período, os estudantes evoluem até a entrega de um **projeto final completo**, acompanhado também na disciplina de **Gerenciamento de Projetos**.

---

## Ementa
Desenvolvimento de aplicações móveis: **componentes e layout**, **estilização**, **navegação**, **estado e eventos**, **consumo de WebServices/APIs**, **persistência local (SQLite)**, **autenticação**, **integração com back-end**, e **projeto prático** com entrega final.

---

## Conteúdo programático

### 1º Bimestre
- Introdução ao **React Native + Expo**
- Componentes, layout, **StyleSheet** e responsividade
- Navegação (Stack/Tab) e organização do projeto
- Consumo de API (HTTP) — fundamentos

### 2º Bimestre
- **Persistência local** com SQLite (CRUD e consultas)
- Validação de formulários e padrões de UX (loading/empty/error states)
- Autenticação (JWT) e interceptação de requisições
- Integração com API (NestJS) — fundamentos

### 3º Bimestre
- Projeto avançado: **Offline-first** + **sincronização** (push/pull)
- Controle de acesso **RBAC**
- Upload de mídia/anexo
- Indicadores/relatórios e refinamentos de qualidade (testes/CI)

### 4º Bimestre *(se aplicável ao calendário da turma)*
- Evolução do projeto / Seminários / Apresentações
- Empacotamento, documentação e entrega final
